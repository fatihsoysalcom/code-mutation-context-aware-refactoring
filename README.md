# Code Mutation Context Aware Refactoring

This example demonstrates the core concept of 'mutating code content' by comparing a naive approach with a more context-aware one. It shows how a simple string replacement (analogous to a basic RAG system) can lead to incorrect code changes due to lack of semantic understanding. In contrast, a 'MemStrata-like' approach applies changes only within the intended scope, highlighting the importance of context in code mutation.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run `python main.py` in your terminal.
